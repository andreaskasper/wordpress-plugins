## Visiting the website

When you open a page, your browser automatically sends technical data to our web server, such as your IP address, the date and time of the request, the address of the page requested, the referring page, and browser and operating system information. The server stores these data in log files.

We use them to deliver the website, to keep it stable and secure and to detect and investigate attacks. We keep log files only as long as needed for these purposes, usually no longer than a few weeks, unless an incident requires longer storage.

The website is hosted by {{site.hosting_provider}}, which processes these data on our behalf.
